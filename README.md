Student Grade Calculator

A beginner programming project created using RAPTOR flowcharts.

📌 About the Project

This project is a simple Student Grade Calculator created to practice programming logic and algorithm design using a flowchart.

The project takes the required marks as input, performs calculations, and determines the student's grade based on the conditions defined in the flowchart.

🧩 Files in This Repository
RAPTOR JSON file — The saved RAPTOR project containing the flowchart structure.
Flowchart PNG/images — Visual representations of the completed flowchart.
⚙️ How It Works

The flowchart:

Takes the required marks as input.
Validates the entered values.
Performs the required calculations.
Determines the grade using conditional logic.
Displays the result.
🛠️ Tool Used
RAPTOR — Used to design and test the flowchart.
